# dislop

[简体中文](https://github.com/dislop-ai/dislop/blob/main/README.zh-CN.md) · [dislop.com](https://dislop.com/?lang=en) · [npm](https://www.npmjs.com/package/dislop) · [PyPI](https://pypi.org/project/dislop/) · [Awesome Anti-Slop](https://github.com/dislop-ai/dislop/blob/main/awesome/README.md) · [X (@dislop_ai)](https://x.com/dislop_ai)

`dislop` flags leftover AI chat wrappers, stock phrasing, second-order slogans, rhythm monotony, and template UI before you ship docs, Word or PowerPoint files, or web pages.

- **Open-source offline core ([dislop-ai/dislop](https://github.com/dislop-ai/dislop), Apache-2.0)**: 7 built-in packs (`42` rules), 53 anti-slop patterns, a bundled `14.6 KB` Pocket ML ensemble, 87 vetted tools, and `dislop-bench v2`. Runs locally with zero uploads.
- **Quick CLI check**: `npx --yes dislop check .` or `uvx dislop check .`
- **Cross-host Agent Skill**: `npx skills add dislop-ai/dislop`
- **Official MCP (`io.github.dislop-ai/dislop`)**: local `stdio` (`npx --yes dislop --mcp` / `uvx dislop --mcp`) and optional hosted Cloud Remote MCP (`https://dislop.com/mcp`, 30 free credits/month).
