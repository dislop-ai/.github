# dislop

[简体中文](https://github.com/dislop-ai/dislop/blob/main/README.zh-CN.md) · [dislop.com](https://dislop.com/?lang=en) · [npm](https://www.npmjs.com/package/dislop) · [PyPI](https://pypi.org/project/dislop/) · [Awesome Anti-Slop](https://github.com/dislop-ai/dislop/blob/main/awesome/README.md) · [X (@dislop_ai)](https://x.com/dislop_ai)

**Linter for AI Slop.** Helps you (and your agent) catch and fix AI-sounding text and template layouts in docs, web pages, and slides before sending — built first for coding agent users, then office agent users, and everyone delivering work with AI.

- **Pure-Doc Skill ([dislop-ai/dislop](https://github.com/dislop-ai/dislop), Apache-2.0)**: `npx skills add dislop-ai/dislop` installs genre reference cards (`0` bundled scripts, `0` network calls) so agents avoid clichés before drafting.
- **Open-Source Local CLI & Editor Plugins**: `npx --yes dislop check .` / `uvx dislop check .` run completely offline with 7 built-in packs (`42` rules), 53 anti-slop patterns, a bundled `14.6 KB` Pocket ML ensemble, and 87 vetted tools across Markdown, web UI, Word, and PowerPoint.
- **Official Cloud MCP & Web Workbench (`https://dislop.com/mcp`)**: Sign in (`30` free monthly credits) for multi-model genre review returning structured edit guidance so local agents revise with full project context.
