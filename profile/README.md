# dislop

[简体中文](https://github.com/dislop-ai/dislop/blob/main/README.zh-CN.md) · [dislop.com](https://dislop.com/?lang=en) · [npm](https://www.npmjs.com/package/dislop) · [PyPI](https://pypi.org/project/dislop/) · [Awesome Anti-Slop](https://github.com/dislop-ai/dislop/blob/main/awesome/README.md) · [X (@dislop_ai)](https://x.com/dislop_ai)

**Linter for AI Slop.** Helps you (and your agent) catch and fix AI-sounding text and template layouts in docs, web pages, and slides before sending — built first for coding agent users, then office agent users, and everyone delivering work with AI.

- **Curated community work ([dislop-ai/dislop](https://github.com/dislop-ai/dislop), Apache-2.0)**: 7 built-in packs (`42` rules), 53 anti-slop patterns, a bundled `14.6 KB` Pocket ML ensemble, and 87 vetted tools across Markdown, web UI, Word, and PowerPoint.
- **Broad host and scenario fit**: `npx skills add dislop-ai/dislop` (Agent Skill & Plugin), `npx --yes dislop check .` / `uvx dislop check .` (CLI), and Official MCP (`io.github.dislop-ai/dislop` via local `stdio` or hosted Cloud MCP at `https://dislop.com/mcp`, switchable on `dislop.com`).
- **Local, offline, private**: The CLI and local plugins run completely offline with zero uploads, keeping drafts and source code on your machine.
