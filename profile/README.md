## English

**Cutting AI slop is real productivity.** `dislop` is a linter for AI slop that helps you and your agent catch and fix AI-sounding prose and stock layouts in docs, web pages, and slides before sending. Built first for coding agent users, then office agent users, and everyone delivering work with AI.

- **Pure-Doc Skill ([dislop-ai/dislop](https://github.com/dislop-ai/dislop), Apache-2.0)**: `npx skills add dislop-ai/dislop` installs genre reference cards (`0` bundled scripts, `0` network calls) so agents avoid clichés before drafting.
- **Open-Source Local CLI & Editor Plugins**: `npx --yes dislop check .` and `uvx dislop check .` run offline with 7 built-in packs (`42` rules), 53 patterns, a `14.6 KB` Pocket ML ensemble, and 87 vetted tools across Markdown, web UI, Word, and PowerPoint.
- **Official Cloud MCP & Web Workbench (`https://dislop.com/mcp`)**: Sign in (`30` free monthly credits) for multi-model genre review returning structured edit guidance so local agents revise in full project context.

## 中文

**去 AI 味才是真正的生产力！** `dislop` 是专用的 AI 味检查工具，帮你和你的 Agent 在文档、网页和 PPT 发出去之前，把 AI 寒暄、空话套话和模板布局挑出来并改干净。

- **开源纯文档 Skill（[dislop-ai/dislop](https://github.com/dislop-ai/dislop/blob/main/README.zh-CN.md)，Apache-2.0）**：一行 `npx skills add dislop-ai/dislop` 装好分场景参考卡（不含脚本、0 联网），让 Agent 动笔前先避坑。
- **开源本地 CLI 与编辑器插件**：`npx --yes dislop check .` 或 `uvx dislop check .` 纯本地零上传运行，内置 7 套场景包、Markdown / HTML / Word / PPT 检查与 87 条去 AI 味工具清单。
- **官方云端 MCP 与网页工作台（`https://dislop.com`）**：免本地环境，登录即领每月 30 免费额度，按文体做多模型深度审校并返回结构化改法，也支持保留原排版的 Word / PPT 处理。
