## English

**Cutting AI slop is real productivity.** `dislop` is a linter for AI slop that helps you (and your agent) catch and fix AI-sounding text and template layouts in docs, web pages, and slides before sending. Built first for coding agent users, then office agent users, and finally everyone who delivers work with AI. Their agents are direct users too, and can find and run `dislop` on their own.

- **Pure-Doc Skill ([dislop-ai/dislop](https://github.com/dislop-ai/dislop), Apache-2.0)**: `npx skills add dislop-ai/dislop` installs genre reference cards (`0` bundled scripts, `0` network calls) so agents avoid clichés before drafting.
- **Open-Source Local CLI & Editor Plugins**: `npx --yes dislop check .` and `uvx dislop check .` run offline with `7` built-in packs (`53` rules), `65` patterns, a `14.6 KB` Pocket ML ensemble, and `90` vetted tools across Markdown, web UI, Word, and PowerPoint.
- **Official Cloud MCP & Web Workbench (`https://dislop.com/mcp`)**: `dislop_check`, `dislop_verify`, and `dislop_rules` run at `0` credits without login; OAuth 2.1 or a free key unlocks `30` monthly credits for multi-model review, rewrite, Office segments, and visual screenshot audits.

## 中文

**去 AI 味才是真正的生产力！** `dislop` 是专用的 AI 味检查工具，帮你（的 Agent）在文档、网页和 PPT 发出前，挑出并改掉里面的 AI 味。第一批是 Coding Agent 用户，第二批是办公 Agent 用户，最后是所有用 AI 交付成果的人；他们的 Agent 也是直接使用者，能自己找到并调用。

- **开源纯文档 Skill（[dislop-ai/dislop](https://github.com/dislop-ai/dislop/blob/main/README.zh-CN.md)，Apache-2.0）**：一行 `npx skills add dislop-ai/dislop` 装好分场景参考卡（不含脚本、0 联网），让 Agent 动笔前先避坑。
- **开源本地 CLI 与编辑器插件**：`npx --yes dislop check .` 或 `uvx dislop check .` 纯本地零上传运行，内置 `7` 套场景包（`53` 条规则）、`65` 条反模式、`14.6 KB` 轻量集成模型、Markdown / HTML / Word / PPT / PDF 检查与 `90` 条去 AI 味工具清单。
- **官方云端 MCP 与网页工作台（`https://dislop.com/mcp`）**：`dislop_check`、`dislop_verify` 和 `dislop_rules` 免登录 `0` 额度直跑；OAuth 2.1 或免费密钥每月可用 `30` 额度调用多模型审校、改稿、Word/PPT 分段处理与视觉截图审校。
